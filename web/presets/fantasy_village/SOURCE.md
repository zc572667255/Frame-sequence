# 魔幻村庄 2D 横版游戏素材包

以「明亮版魔幻村庄」场景为设计参照，将可摆放的主体重绘为独立 PNG。所有独立场景物件和视差层均为 **RGBA 真透明**；不包含天空、云层或额外的落地投影。原场景是单张合成图，物体遮挡部分属于重新补绘，并非逐像素还原。

## 追加的村庄道具

`sprites/` 里另有 16 个透明道具（水井、野花、符文石、吊灯、路标、告示板、长凳、木桶、木箱、麻袋、草垛、宝箱、陶罐、手推车、原木堆、藤筐），由四张 2×2 道具图切出：原图背景已是透明，只去掉了物体周围一圈很淡的光晕（透明度低于 16 的像素），每个物体按它所在的格子归组后裁切，留 2 像素边。`manifest.json` 里的 `w` 是它在示例村庄比例下的建议显示宽度。

## 目录

- `sprites/`：10 个透明素材：锻造屋、民居、古树、魔法祭坛、灯柱、木栅栏、旗帜、灌木、浮空遗迹和远山层。
- `atlases/village_sprite_atlas.png`：将上述独立素材打包的透明精灵图。
- `atlases/village_sprite_atlas.json`：每个素材在精灵图中的像素坐标 `[x, y, width, height]`、源文件和建议枢轴。
- `tiles_16x16/`：16 张独立的 **16×16** RGBA 地形图块及其 `terrain_atlas_16px.png`，四列四行，每行依次为沙地、草地、泥土、石面，每种 4 个外边界相同的可互换变体。
- `tiles_16x16/grass_top_overlay_x_only.png`：草地上缘叠加图块，只保证**横向**无缝；不要纵向重复。
- `preview/`：拼合示意、透明精灵图预览和沙地无限重复检测图，这些仅用于检查，不是游戏素材。

## 16×16 地面无缝保证

独立的 `sand_00.png` 至 `sand_03.png`（其他材质同理）都是 **16×16 像素，不含边距**：

1. 每张图片左列与右列像素完全一致；上行与下行像素完全一致。
2. 每个同材质变体具有相同的四周边界，因此可以在任何水平和垂直方向重复，亦可混用变体。
3. 图块采用非常浅的大色块变化，避免形成机械重复纹理；在纯色基础上添加个别局部色差。
4. 脚本逐张检验了像素尺寸、四边对应和不透明度，并输出 `preview/sand_12x8_repeat_test.png` 和 `preview/sand_variants_repeat_test.png`。

**注意：**这里的「完全无缝」指色彩边界无不连续；地图衔接不等于实际地形具有高度变化或自动铺边功能。`grass_top_overlay_x_only.png` 用于平台上缘，纵向边界不等色，也不应当做整片地面铺设。

## Godot 4 建议用法

1. 将 `tiles_16x16/terrain_atlas_16px.png` 导入项目。给 `TileMapLayer` 建一个 TileSet Atlas Source，图块区域设为 `16×16`，网格 `4×4`，`Margins=0`、`Separation=0`。
2. 使用 `sand_00`（图块坐标 `(0,0)`）铺出沙土地面；为减少重复感，随机穿插同一行的另外三个变体。
3. 建筑、树木、祭坛用单独 `Sprite2D`；建议以底部中间为视觉落点。直接使用 `sprites/` 下的独立 PNG，更方便调整缩放和遮挡顺序。
4. 山峦、浮空遗迹放在单独的 `Parallax2D` 层，视差滚动比例可比近景小。山峦层**没有做横向循环接缝保证**，如果需要无限远景请单独扩展或镜像拼接。
5. 对 16×16 精确像素图块，使用 `Nearest` 纹理过滤；建筑原画适合 `Linear`。如果项目采用统一的渲染过滤，建议分别配置不同的 CanvasItem texture filter。
6. 云、投影、天气、粒子可以用 Godot 的程序效果或简单图形实现，本素材包没有把它们焊死在房屋、地形上。

## 比例与用途

房屋等透明素材按插画像素大图保存，适合在引擎里按目标角色高度**统一缩放**，避免预先降采样损失画质。地面图块是严格原生 16px，插画建筑与 16px 图块本身不是同一物理比例，应在具体游戏镜头中调整。风格参考来自原始场景和红披风角色设定，明亮日系奇幻漫画、低噪点。
