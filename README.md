# 光台 · 序列帧工作室

本地运行的序列帧工具：无限画布 + 节点流程。把序列帧图拖进来，串起「去背景 → 完美像素 → 切片 → 对齐 → 调色 → 预览 / 导出」，每一步都能单独调参、旁路或替换，结果实时更新。

原来的单页工具 `序列帧动画工具.html` 保留不动，启动后也可以从「项目菜单 → 打开旧版单页工具」访问。

## 启动

需要 Node.js 18 或更新版本，没有其他依赖。

- 双击 `start.bat`，会自动打开浏览器；
- 或者在命令行运行 `npm start`，然后访问 http://127.0.0.1:5288/ 。

关掉 start.bat 的窗口，服务就停止了。

## 项目保存在哪

每个项目就是一个普通文件夹，默认建在 `projects/<项目名>/`，新建时也可以选任意位置：

```
<项目文件夹>/
  project.gtproj   项目文档：卡片、连线、参数，以及视角、选中状态等界面状态
  assets/          图片素材（按内容哈希命名，同一张图只存一份）
  backups/         自动历史版本（每 10 分钟最多一份，保留最近 30 份）
```

- 改动会自动保存（约 0.7 秒后写盘，Ctrl+S 立即保存），关闭页面时没写完的改动也会补存。
- 重新打开会回到离开时的样子：画布位置和缩放、选中的卡片、每张卡片的视图开关、主题和面板开关。
- 项目菜单里可以新建、打开（选 `.gtproj` 文件）、另存为、查看历史版本、在资源管理器中显示。
- 「清理未使用素材…」：编辑过的帧会在 assets 里留下旧版本，清理时把当前项目、全部历史版本和撤销记录都不再引用的素材移到 data/trash（不直接删除）；像素编辑器打开时不能清理。
- 最近项目列表和设置记在 `data/registry.json`，不依赖浏览器缓存。删除项目会把文件夹移到 `data/trash/`，不会直接删掉。

## 用法速览

| 操作 | 方式 |
|---|---|
| 导入图片 | 把文件拖到画布上；或 Ctrl+V 粘贴；或点左上「＋ 图片」 |
| 导入序列帧 | 左侧「⇶ 序列帧」：多张图片（按文件名数字排序）、整个文件夹、GIF / WebP / APNG 动图、或一张图里排了多帧的整图（自动识别网格）；直接把多张图或文件夹拖到画布也行。得到一张「动画」卡片 |
| 一键生成流程 | 右键素材图卡片 →「生成标准处理流程」；或「切成动画…」直接把整图切成动画卡片 |
| 添加节点 | 双击空白处搜索；从左侧栏点击或拖入；从输出端口拖线到空白处（只列出能接上的节点） |
| 连线 / 断开 | 从输出端口拖到输入端口；拖动已连接的输入端口可以把线拔下来 |
| 跳过某一步 | 卡片标题栏的「旁路」 |
| 在卡片上操作 | 去背景：「取样」后点图取色；切片：点格子排除帧；调色：「画笔 / 橡皮 / 魔棒」直接在图上涂 |
| 保存成可编辑动画 | 右键 →「烘焙为动画卡片」，每帧存为项目里的图片 |
| 画布 | 滚轮缩放、空格或中键拖动平移、拖空白处框选、按住卡片（包括图片）任意位置拖动、F 适应视图 |
| 撤销 | Ctrl+Z / Ctrl+Y，拖动、涂抹、调滑块都会合并成一步 |

## 像素编辑器

双击「动画」卡片打开。动画卡片可以由任意处理结果「烘焙」得到，也可以从左侧栏新建一张空的从头画（默认 32×32，用「画布尺寸」修改）。

- 左侧工具：铅笔 B、橡皮 E、填充 G、吸管 I（任何绘制工具按住 Alt 也是吸管）、直线 L、矩形 U、椭圆 Shift+U、选区 M、移动 V

拉伸棍子跟着武器走（切到下一帧时自动沿用上一帧的棍子），每帧的拖尾由最近几帧棍子扫过的区域自动生成。挥到顶峰后不再放棍子，后面几帧按「收尾消散」自动渐隐（头停住、尾追上、变淡）；帧与帧之间按握柄旋转插值，刀尖走圆弧，「挥动方向」可指定顺时针 / 逆时针（只有两三帧的大幅挥砍方向有歧义时用，从左上经头顶劈到右下选顺时针），「弧度」可整体外鼓 / 刀芯描边、由外向内的主色渐变、流体（顺着挥动方向流动翻卷的火焰 / 水流 / 能量纹理，内侧碎成火舌）、几十条尖头细光丝叠加发光、辉光、残影；点缀有闪烁四角星、粒子粉尘、玻璃碎片、起手闪光（第一根棍子处的星芒和光环）、命中爆点（最后一根棍子处的闪光、放射线和碎屑，随收尾扩散）、飞溅墨点、卡通阴影（刀芯偏移一道暗色影子）、闪电（雷光 / 尾色可调；各层的搭配由预设决定，面板上所有光效共用同一组按位置分的总控：刀锋（刀芯、结晶、光芒、阴影）、刀身（光丝、流体、火舌、闪电、速度线）、光晕（辉光、残影）、粒子（星光、粉尘、雪花、余烬、碎片、飞溅）、爆发（起手闪光、命中爆点），0–200%、100% 硬边，辉光自动收紧，细光丝、粉尘、星光、起手闪光、命中爆点等细碎点缀自动减弱，像素化时先把颜色往饱和方向拉（叠加光缩小后容易发白），再像像素画师手修一样清理：去掉孤立的淡色杂点、和四周都不同色的单个像素改成周围的颜色，色层干净不起颗粒；从高清切到像素时保留当前预设；经典色带和弧光系列配色按手绘刀光重调：刀尖一侧白亮边、浅亮色、饱和主色、内侧是偏色的深色而不发黑；色带拖尾收尾消散时不再整体变淡或变成棋盘格抖动，而是从内侧往刀尖一侧越收越细、沿长度断成几截再消失；再列「经典色带」，含弧光系列（冰蓝弧光、烈焰弧光、金辉弧光、暗影弧光、翠风弧光、赤红旋斩、水刃：刀尖一侧一道亮边、往握柄一侧变暗并碎成一缕缕渐隐，带速度线，月牙形）和经典色带（白光、火焰、冰霜、雷电、暗紫、鲜血、圣光金、风刃、岩土、主色：4–5 级色阶、亮边在刀尖一侧的硬朗月牙，带少许破碎和速度线）；色带可调「亮边位置」（居中 / 外缘）、内侧（边缘）渐隐、破碎（沿挥动方向拉长的噪声让边缘和色带交界参差、外缘后段有缺口）、速度线、分条（拆成几道平行细条，适合旋斩的多层环，配合「横扫」）、渐隐方式（抖动全实心 / 4 级透明），以及粒子 / 碎片 / 飞溅 / 命中爆点（默认关闭，与高清同样的画法，再吸附成本拖尾色带里的实心像素）；相邻色带之间可选色阶（自动插入两级中间色）/ 抖动 / 平滑渐变 / 硬边过渡，「过渡宽度」调过渡区占多宽，「尾部变暗」让越往尾部越偏外圈暗色、亮芯集中在刀头，都不产生半透明像素；色带与拖尾笔共用（白光、火焰、冰霜、雷电、暗紫、鲜血、圣光金、风刃、主色，横向分层色带）；尾部质感默认「笔刷」——顺着挥动方向的长短刷痕，可选内置毛刷 / 干刷或导入灰度图作为自定义笔刷，也可切回颗粒抖动或平滑渐隐；棍子两端标着「柄」「尖」，画反了（刀尖在握柄一侧，会把拖尾拧成麻花）会自动对调，也可手动「对调两端」，旧数据渲染时同样自动纠正；每帧可设角色前方 / 后方；连招多段拖尾：「＋ 下一段」新建下一刀（沿用当前样式，各占一个图层，自动跳到上一段结束后的那一帧，上一段最后的棍子作为虚线起点可直接拖来接着挥），列表显示每段的帧范围、点一下跳过去，已经画成一段的可在任意帧「从这帧拆开」，各段可用不同样式、时间可以重叠；形状（尾细头粗 / 两头尖月牙：头端也像尾巴一样收细、渐隐、碎成刷痕，光效会把头端也按尾巴画法画出，渐隐长度两端各占一半 / 均匀）、拖尾长度、单色 / 渐变 / 原色、纹理导入与反色、头部弧度、透明渐隐、细腻度（默认 20）、像素化；样式可存为命名预设。拖尾随动画保存，动画卡片的输出、导出和角色包都自动带上；也能栅格化到「特效」图层手修
- 拖尾笔 T：按住拖出一道刀光，松手落笔；先选「高清 / 像素」，像素下同样有「像素光效」（可调像素大小、透明方式）和经典色带：高清光效样式（梦幻、烈焰斩等，与攻击拖尾相同的发光画法，宽度可到 240px）或像素色带样式：白光、火焰、冰霜、雷电、暗紫、鲜血、圣光金、风刃和主色单色样式，可调宽度、形状（尾细头粗 / 两头尖 / 均匀）、尾部渐隐、色带过渡（色阶 / 抖动 / 平滑 / 硬边，过渡宽度、尾部变暗）、尾部质感（笔刷刷痕 / 颗粒抖动，笔刷与攻击拖尾共用，可导入自定义笔刷，不产生半透明）、火花点；默认画到自动新建的「特效」图层
- 特效工具 F（左侧工具栏「特效」）：和攻击拖尾一样，先选一帧，点「特效」就在这一帧新建一个特效图层（画布正中，时间轴上 ✦ 标记；沿用上次用的类型、配色和画风），右侧显示它的参数：高清 / 像素（默认高清）、特效类型（带缩略图，含流光；换成环绕光时自动套住附近有内容的图层并放到它下面）、配色、宽高和位置、开始帧（「从本帧开始」）、特效帧数、循环、持续帧数、大小、粒子、辉光、地面倾斜、法阵图案、闪电、视角（翅膀、冲击波、魔法阵的正面 / 侧面）、旋转、随机样子，「＋ 新特效」再加一个；选中特效图层时在画布上拖动就是移动，拖画幅框的边或角改大小（对边不动，Shift 保持比例，Alt 以中心缩放，「特效大小」只缩放画幅框里的特效）；拖滑块、拉画幅框或在被跟随的图层上画画时特效先出快速草图，松手后出完整画质，时间轴缩略图在空闲时分批重绘，编辑不卡顿；「逐帧调整」打开后每一帧可以单独设位置和大小（拖动或滑块即在本帧设关键帧，时间轴上显示 ◆，没设的帧在前后关键帧之间平滑过渡）；「跟随图层」让特效区域每帧自动套住某个图层的轮廓并按「外扩」放大（角色走到哪斗气跟到哪）；「转为像素图层」把每帧的特效画进普通图层以便手修；特效图层随动画保存，卡片输出、导出都带上，不能直接画或合并；撤销 / 重做时当前图层保持选中
- 残影（时间轴「残影 ＋ / －」）：到要加残影的帧点「＋」，这一帧就把前几帧的画面复制到身后（第一次会在当前图层下方新建残影图层），点「－」去掉；残影图层那一行紫点表示已加入的帧，设置面板上也有「本帧」「全部帧」「清空」，复制帧时一起带上；做冲刺、快速挥动的残影，不用手画、跟着动画变化；可选复制哪个图层（默认当前角色图层，或所有像素图层；拖尾和其他残影不算）、数量、间隔几帧、浓度（越远越淡），颜色可选纯色剪影 / 原图 + 染色 / 原图颜色，近处到远处两种颜色渐变，透明方式可选半透明或像素抖动（像素画不留半透明像素，越淡越稀疏），混合可选正常或发光叠加，「遮挡」（默认 100%）让残影挡住它下面的图层（特效、拖尾）和更远的残影，半透明残影也分得清前后（0% 为旧的透出效果），每个残影可再按 X / Y 偏移（每个残影最多偏移画布宽 / 高的一半，至少 ±32px；原地跑的冲刺动画也能拉出残影），可选循环动画（开头几帧用结尾的帧）；预设冲刺蓝影、暗影、炎影、原色淡影、像素残影；「导出给程序」：Godot 脚本（afterimage.gd，Godot 4，挂到角色精灵下的 Node2D 上，运行时按真实移动留残影，设置和选中的帧已填好，支持 AnimatedSprite2D / Sprite2D、像素抖动和发光叠加）或通用 JSON 参数（附透明度、颜色、位置、抖动的计算公式，供 Unity / Cocos / 自研引擎实现）；残影图层不能画、不能合并，随动画保存，卡片输出和导出都自动带上
- 左键用主色、右键用副色；X 交换；[ ] 调笔刷大小；铅笔默认开启「像素完美」，自动去掉斜线上的 L 形拐角
- 底部时间轴：图层是行、帧是列；点格子切换帧和图层；可以设每帧时长、帧率、洋葱皮（前后各几帧）、图层显示 / 锁定 / 不透明度、合并
- 有选区时只在选区内绘制；移动工具没有选区时移动整层；方向键 1px 微调；Shift+H / Shift+V 翻转；Ctrl+C / X / V 复制剪切粘贴，也能粘贴系统剪贴板里的图片
- 编辑器里有自己的撤销历史；「保存」只上传改动过的格子，卡片和下游的预览、导出立即更新，在画布上算一步撤销

## 调帧台（角色）

在动画卡片上右键「加入角色…」，或从左侧栏添加「角色」卡片，双击打开调帧台。

- 一个角色下挂多组动画（待机、跑、攻击…），来源是画布上的任意动画卡片或处理结果；源卡片更新后自动跟着变
- 所有动画共用一个原点（脚底）：「自动校准原点」把每组可见像素的底部中心对到原点，切换动画不跳位
- 三级变换：单帧 / 动画组 / 角色，各有偏移、缩放、旋转、水平翻转；单帧还能设时长、禁用；工具 1–3 切换拖单帧 / 拖整组 / 拖角色，方向键微调
- 刀光、光效等叠加效果在像素编辑器里用「拖尾」笔画在特效图层上，调帧台里看到和导出的就是画好的帧
- 音效：把 WAV / MP3 / OGG 拖到帧上即可绑定，播放时触发
- 导出角色包（zip）：所有动画同一块画布、同一个原点，每组一张序列图（或 PNG 序列，序列图排列可选一行 / 一列 / 接近正方形 / 自定列数），character.json 记录画布尺寸、原点、逐帧时长和音效，音频一起打包；把 zip 拖回画布即可还原
- 「特效」节点（素材）：不依附刀光、单独生成一段特效序列帧——命中火花（白热闪光、十字尖刺、飞溅火花、细环）、爆炸（白热的火球膨胀，一团团翻滚的火焰向外翻出火舌，从白热经配色冷却，再变成被顶光照亮、一团团翻滚的烟往上飘、逐渐消散，带闪光、冲击环和沿抛物线飞出的火星；黑炎这类深色配色画成翻滚的墨团）、冲击波（环内一层向外推开的柔和能量波，前沿是明亮的环，向外扩散，可压扁成地面冲击波，前沿有速度线和沿弧线扬起、带拖尾的碎屑）、烟尘（向两侧滚开的烟团，上亮下暗，带飞出的小石子）、蓄力（带亮头的弯曲彗尾沿螺旋汇聚到脉动的能量球，外绕两端渐隐的旋转光弧；不循环时最后爆开）、魔法阵（双圆环、符文带、刻度、六芒星 / 五芒星 / 双方形，内外反向旋转，外圈可加「边缘特效」：自动按配色（烈焰斩、炎爆等火系配色是火焰，岩崩是岩石，疾风是风刃，激流是水波，雷光、紫电等是闪电），也可手动选火焰（一圈摇曳的火舌和上飘的火星）、岩石（一圈浮起、起伏自转的碎岩，小石子蹦起落下）、风刃（绕法阵盘旋上升、越往上越收窄的风带和掠过的气流）、水波（外圈起伏流动的水浪、地面涟漪、跳起的水滴）、闪电（沿外圈跳跃的电弧和往上窜的电光）或无，侧面视角下也跟着法阵走；按透视直接矢量绘制在地面上，压扁也不出锯齿，每条线是细亮线加柔和辉光，几道高光沿圆环流转，带上飘的光点；不循环时先逐笔画出再淡出）、治疗光圈（参考游戏光柱：地面柔光和发光圆环、扩散的内环、柔边光柱、盘旋上升的光带、十字光点和闪烁星光）、环绕光（超级赛亚人式斗气：随气流摆动、向上拉长的光焰包住区域，焰中有流动的亮丝、顶部散成光缕，中间透明，柔边光束和带拖尾的火花上升，可加带辉光和分叉的锯齿闪电）、燃烧（从区域底部烧起的火焰：整体随气流摆动，火舌拉长弯曲、内含顺着火舌流动的亮丝并在边缘散成火缕，根部白热、底部柔和淡入，带拖尾的火星上飘；默认配色烈焰斩）、流光（几条柔和起伏的光带横穿区域，每条是一束会扭转的细丝、边缘更亮、两端渐隐，交叠处自然发白，带闪烁光尘；不循环时从左扫入再淡出）；高清模式下烟火类特效边缘柔和过渡，消散时整体变淡成烟缕而不是碎成颗粒，大尺寸时按特效大小自适应降低计算分辨率再平滑放大（更快也更顺滑）；一次性特效的最后几帧保留余韵，不出现空白帧、翅膀（光做的翅膀，重神不重形：每只翅膀有真实翅膀的结构：一条从翼根向外上方拱起的亮翼骨，羽毛沿翼骨生长，靠中心的朝外下方垂、越往外越长越朝外、到翼尖收成上翘的尖，但每根羽毛都画成一缕发光的细丝，下缘是一片参差的火焰状羽毛尖；翼根交汇处一团最亮的光，淡淡的光幕，周围星点闪烁；丝缕随时间轻轻波动；扇动参考鸟和蝴蝶：下扑快、上抬慢，正面时翅膀上抬会往背后合拢变窄、下拍完全张开，侧面时翅膀绕肩部从接近竖直摆到水平线以下、上抬时在腕部收短，丝缕跟在动作后面；循环时完整扇动一次，不循环时展开、轻扇一下再散成光点；正面是左右一对，侧面是向后展开的近翼和后面略小略暗的远翼）；所有特效的粒子（火星、光点、碎屑）都是带拖尾的彗星粒子，拖尾顺着各自的运动轨迹弯曲（下落的火星是抛物线、摇曳上升的光点是波浪线），头部发亮；配色用拖尾光效的同一套预设（每种特效有默认配色、帧数和是否循环），可调大小、粒子、辉光、地面倾斜、法阵图案、随机样子；翅膀、冲击波、魔法阵可选「视角」正面 / 侧面（翅膀向后展开，冲击波和魔法阵竖起来侧对着，像一道传送门；其他特效从哪边看都一样，不提供这个选项，切换到它们时自动回到正面），所有特效都可用「旋转」（整体绕中心转动，转出画幅的部分会被裁掉）；画风高清或像素（像素大小 1–4、4 级透明 / 抖动 / 硬边，颜色吸附到预设色板，烟尘颜色也加入色板；像素模式下柔光柱、地面光晕这类大片淡光自动省略，避免变成色块）；循环特效首尾无缝衔接；可烘焙为动画卡片后在像素编辑器里手修
- 「补帧」节点（处理）：只处理 128×128 以内的像素小图（更大的原样输出并提示先缩小），在每两帧之间插入中间帧（×2 / ×3 / ×4），让动作更顺滑；小图用 4×4 的块匹配，「保持像素」默认打开；「运动估计」用金字塔块匹配估计前后两帧的运动（透明度也参与匹配），再把两帧都推到中间位置合成，「动作幅度」决定能追踪多远的移动，「淡入淡出混合」直接叠化；原帧时长平均分给插入的帧，总时长不变；可首尾循环补帧、「保持像素」（像素画不留半透明，颜色吸附回原画用色）。平移和小幅动作效果好，大幅挥动、快速旋转、细长物体转动会出现撕裂或重影
- 导出节点的「GIF」：先检查半透明像素占比（光效、辉光、渐隐），较多时提示 GIF 只有全透明 / 不透明两档，可改导出 WebP、垫底色导出 GIF 或照常导出
- 导出节点的「序列图」：先弹出设置框，选排列（一行 / 一列 / 接近正方形 / 自定列数）和列数，实时显示几列几行、空几格、整图尺寸和预览，选择会记在节点上；检查器「排版与时间」里也能改
- 也能导入单独的「序列图 + JSON」：本工具导出的、Aseprite 或 TexturePacker 的 JSON 都认

## 代码结构

```
server/            零依赖 Node 服务：静态文件 + 项目 / 素材 API（只监听 127.0.0.1）
web/
  index.html
  css/app.css
  js/
    main.js        App：项目、菜单、顶栏、左侧栏、烘焙、标准流程
    core/          store（文档 + 撤销）、api、assets（素材缓存）、工具函数
    imaging/       纯算法：去背、完美像素（FFT 网格检测）、归位、对齐、调色、切片、补帧（运动估计插帧）、GIF、ZIP
    vfx/           独立特效：effects（命中火花、爆炸、冲击波、烟尘、蓄力、魔法阵、治疗光圈、环绕光、燃烧、流光、翅膀；翅膀、冲击波、魔法阵有侧面视角，所有特效可旋转；复用拖尾光效的配色、形状和像素化）、layer（特效图层：开始帧与持续、固定 / 逐帧关键帧 / 跟随图层轮廓的区域、渲染缓存按张数和总像素封顶）
    nodes/         节点系统：registry（类型定义）、engine（按参数和输入版本缓存的求值）、
                   view（卡片里的显示区 / 播放器 / 胶片条）、types/（每种节点一个文件）
    board/         无限画布：平移缩放、卡片、连线、框选、复制粘贴、拖放
    ui/            属性面板、表单控件、菜单、对话框
    editor/        像素编辑器：doc（图层 × 帧的文档与撤销）、raster（像素操作）、trailbrush（拖尾笔）、editor（界面与工具）
    trails/        攻击拖尾：model（逐帧棍子 → 拖尾网格、像素色带）、glow（光效预设、总控和组装）、glow/（util 工具、shapes 形状、layers 拖尾身上的层、fx 周围点缀、finish 像素化与平涂）、uv（像素在拖尾上的 u / v 坐标）、composite（纹理加载；渲染缓存只存拖尾覆盖的区域、按像素总量封顶；拖动棍子或滑块时高清光效先出半分辨率预览，松手后出完整画质）；ghost（残影图层：前几帧的着色副本，带缓存）、ghostexport（残影导出成 Godot 脚本 / JSON 参数）
    tuner/         调帧台：model（共享原点与三级变换的渲染）、tuner（界面）、export / import（角色包）
scripts/check.js   对所有 JS 做语法检查：npm run check
```

新增一种节点：在 `web/js/nodes/types/` 下建一个文件，调用 `defineNode({...})` 定义输入输出、`evaluate`（计算）、`mount`（卡片内容）和 `inspector`（属性面板），再在 `types/index.js` 里引入即可。
